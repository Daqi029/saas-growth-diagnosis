# Activation and onboarding diagnosis

Activation is the first time a user experiences the product's core value. Registration, profile completion, a product tour, or watching a tutorial is not activation unless it produces the promised result.

## Layer 1: define and validate the Aha Moment

A candidate activation event should be:

1. value-bearing: it solves a real user problem or creates a perceptible result;
2. measurable: the event can be tracked consistently;
3. predictive: users who complete it retain or pay materially more than comparable users who do not;
4. reachable: a new user can complete it within the product's realistic early-value window.

Ways to identify it:

- compare early actions of retained and churned cohorts;
- ask active users when they first felt the product was useful and what they did;
- inspect repeated patterns across successful users;
- use competitor patterns only as hypotheses, never as the final definition.

If completion does not predict later success after controlling for user intent, it is probably a vanity activation event.

## Layer 2: shorten the path to value

Map every step from signup to the candidate Aha Moment and calculate step conversion. Prioritize the largest avoidable drop before the value event.

Directional source signals:

- fewer than 30% reach value within seven days → activation path probably needs work;
- 40% reach value within 48 hours → directionally acceptable;
- 50% reach value within 24 hours → directionally strong.

Adjust expectations for products with genuine setup, integration, compliance, or multi-person requirements.

Common blockers:

- too many registration fields or synchronous verification steps;
- a blank first state with no meaningful example;
- mandatory team invitations, integrations, or data imports before any value;
- a long feature tour instead of one guided task;
- setup questions collected before they improve the first result;
- no clear next action or progress feedback;
- generic onboarding for distinct jobs or segments.

## Layer 3: guide the first meaningful task

Prefer:

- sample data, a prefilled artifact, or a relevant template;
- a guided task that produces a real output;
- three to five value-bearing checklist items when a checklist helps;
- contextual guidance at the moment of difficulty;
- progressive profiling after value;
- behavioral reminders linked to an unfinished valuable task.

Avoid celebrating setup work as success. “Profile complete” matters only when it enables the user's intended outcome.

## Evidence to request

- activation definition and event schema;
- activation rate by cohort and channel;
- median and distribution of time to value;
- step-level onboarding funnel;
- retained versus churned early actions;
- five to ten session recordings around the biggest drop;
- interviews with both successful and stalled new users.

## Candidate experiments

- Replace a blank state with a prefilled, editable example matched to the main job.
- Remove or defer one setup step before first value.
- Replace a feature tour with a guided first task.
- Let one user experience value before requiring team invitation or integration.
- Trigger help when behavior shows hesitation, not on an arbitrary timer.
